## 已知問題與限制

- 攻城戰在伺服器算；強盜戰、演習還在瀏覽器算，伺服器只擋明顯不合理的數值（擊殺數、存活數、最短時間）
- 開發機的 Chrome 沒有用到顯示卡（Microsoft Basic Render Driver），效能數字偏低；裝好顯示卡驅動後要重新量
- 舊版存在瀏覽器裡的存檔不會自動匯入帳號
