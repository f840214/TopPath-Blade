## 接下來（依順序）

### 1. 攻城強化（《戰意》★4）
- [ ] 衝車：兵團推動，破門比徒手快很多；守方可以優先集火
- [ ] 雲梯：搭在城牆上變成第二條入城路線，守方可以推倒
- [ ] 可破壞的城牆段：牆段有血量，打掉後變成可通行的缺口並留下瓦礫
- [ ] 多段據點：外城 → 內城 → 主堡，依序佔領；佔領後成為我方重生／集結點
- [ ] 攻城表現：城門分段破損圖、破門瞬間煙塵與短暫慢動作、落石與投石落點預警

### 2. 灰燼式地形
- [ ] 地形元素：石牆、山脊（高低差）、土路、岩石、樹林，會擋路或影響移動
- [ ] 尋路升級：現在只會「繞到城門」，要改成能繞開任意障礙（flow field 或網格 A*）
- [ ] 地圖製作方式：程式產生或用 Tiled 編輯器畫，匯出 JSON 給遊戲讀
- [ ] 地形效果：高處弓兵射程加成、樹林減少受到的遠程傷害、土路移動加速

### 3. 戰場表現（研究報告 7.5 節）
- [ ] 控制效果的動作：倒地（旋轉 90° 再起身）、擊飛（影子留在地上）、恐慌（頭上「!」、背向敵人跑）
- [ ] 屍體與血跡烘進地面圖層（有上限、可關閉，效能不受影響）
- [ ] 擊殺提示（右上角文字串，武將級擊殺加圖示）
- [ ] 關鍵時刻短暫慢動作：敵將被擊殺、城門破開、最後據點翻轉
- [ ] 箭雨表現：箭插在盾上或地上、齊射加隨機時間差
- [ ] 小地圖、按住鍵拉遠看全戰場

### 4. 士氣、潰逃、天氣
- [ ] 士氣：被側擊或背擊、主將陣亡、兵力過低時下降；歸零的兵團潰逃
- [ ] 潰逃的視覺：陣型打散、旗子倒下、士兵背向敵人跑
- [ ] 天氣：雨天火箭點不著、霧天射程降低；畫面加雨絲、色調

### 5. 成長系統補完
- [ ] 敵方兵團依戰場難度帶預設老兵配置
- [ ] 騎兵補員另需馬匹；兵力過低時的戰力懲罰
- [ ] 裝備掉落與打造（現在裝備全部一開始就能選）
- [ ] 武將屬性點或天賦

### 6. 戰略大地圖（design.md 第 8 節）
- [ ] 大地圖：多座城池與據點、軍隊行軍、時間流動
- [ ] 出征遇敵或抵達敵城時進入對應戰場；戰後結算回到大地圖
- [ ] 佔領城池提供收入與募兵；敵方勢力會反攻（觸發守城，取代原本的佈防模式）
- [ ] 營地與補給：糧食、疲勞

## 部署與維運

- [ ] **公開上線前一定要加 HTTPS**：在 8899 前面放反向代理（Caddy、Nginx Proxy Manager 或 Cloudflare Tunnel），並在 `compose.yaml` 打開 `COOKIE_SECURE`；否則密碼會以明文傳送
- [ ] 第一次在伺服器上 `docker compose up -d --build`，確認新的 Node 映像建置成功（開發機沒有 Docker，還沒實際建置過）
- [ ] 定期備份主機上的 `data/` 資料夾（帳號與存檔都在裡面）
- [ ] 玩家變多時改用獨立 PostgreSQL（設定 `DATABASE_URL`）
- [ ] 忘記密碼／改密碼功能（目前沒有）

## 已知問題與限制

- 戰鬥在玩家瀏覽器計算，結果上傳到伺服器；伺服器只擋明顯不合理的數值，**還沒有防作弊**（多人連線第 2、3 階段處理）
- 開發機的 Chrome 沒有用到顯示卡（Microsoft Basic Render Driver），效能數字偏低；裝好顯示卡驅動後要重新量
- 舊版存在瀏覽器裡的存檔不會自動匯入帳號
